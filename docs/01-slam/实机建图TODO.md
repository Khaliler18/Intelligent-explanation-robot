## B4. 离线建图与质量验收

**目标**：地图质量有客观依据，且"存下来的能再打开"。

- [ ] 回放建图（**bag 路径在 `--ros-args` 之前**）：

  ```bash
  ros2 run glim_ros glim_rosbag ~/slam/data/raw/<bag> \
    --ros-args -p config_path:=$HOME/slam/config/mid360
  ```

  记录：命令、配置、日志、处理耗时、峰值资源占用。
- [ ] **地图质量检查**（查看器内）：墙面是否只有一层（`ColorMode` 设 INTENSITY，取消勾选 `points`）、墙角是否锐利、轨迹是否平滑连续、地面是否薄层。
- [ ] 用**实测尺寸**检查误差，记录可接受阈值。
- [ ] 回环检测：`Find overlapping submaps`，记录找到的回环对数（`N=0` 说明路线无重叠，需补扫）。
- [ ] 全局优化：点 `Optimize` **只点一次**，超过 10 分钟无输出则 `Ctrl+C`，用增量优化结果继续。
- [ ] **保存并备份**：从 `/tmp/dump/` 拷到 `~/slam/output/<批次名>_dump/`。**`/tmp` 重启即清空，这一步不能省。**
- [ ] **验证可恢复**：用 `offline_viewer --map_path ... --config_path ...` 重新加载，确认地图正常显示。
- [ ] 记录已知问题：`T_lidar_imu` 采用单位阵未经标定、IMU 校验警告、玻璃/动态物体造成的缺陷区域。

**验收**：地图质量检查全部通过、误差有实测依据、dump 已持久化备份、重新加载可正常显示。
