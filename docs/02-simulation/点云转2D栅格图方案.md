# 点云地图转 2D 栅格地图方案

> 阶段：02 仿真与导航地图制作
> 负责人：黄凯乐
> 分支：`feature/pcd-to-gridmap`

## 1. 背景与目标

GLIM 离线建图产出的是**自有紧凑二进制格式**的 3D 点云地图 dump（`*_compact.bin`，见 [实机建图 TODO B5](../01-slam/实机建图TODO.md#b5-测试地图数据集交付与接口验证)）。后续小车在仿真中跑导航（Nav2）需要的是标准 **2D 占据栅格地图**（`map.pgm` + `map.yaml`）。

本方案的目标：把 GLIM 的 3D 点云地图转换成 Nav2 可直接加载的 2D 栅格地图，**复用开源工具，不自手敲**。

## 2. 完整转换链路

```
GLIM dump（*_compact.bin）
  ① offline_viewer → File → Save → Export Points   → map.ply（官方导出，二进制 PLY）
  ② PLY → PCD 转换（pcl 工具 / Open3D 一行代码）    → map.pcd
  ③ pcd2pgm（ROS2 包，高度切片 + 滤波）             → OccupancyGrid 话题
  ④ map_saver 保存                                 → map.pgm + map.yaml（Nav2 直接用）
```

## 3. 各环节说明

### ① GLIM dump → PLY

GLIM 官方 `offline_viewer` 自带导出能力：

```
File → Save → Export Points
```

导出为**二进制 PLY**，包含所有子图点云按优化后的全局位姿拼接的完整地图。

参考：[GLIM Offline Viewer and Map Editor](https://deepwiki.com/koide3/glim/6.3-offline-viewer-and-map-editor)

### ② PLY → PCD

`pcd2pgm` 读取 `.pcd`，因此需要格式转换。任选其一：

- **pcl_convert_ply_ascii_binary**（PCL 自带）
- **Open3D**：

  ```python
  import open3d as o3d
  pcd = o3d.io.read_point_cloud("map.ply")
  o3d.io.write_point_cloud("map.pcd", pcd)
  ```

- **CloudCompare**（GUI，适合一次性转换）

### ③ PCD → 占据栅格（pcd2pgm）

使用 [pcd2pgm](https://gitee.com/LihanChen2004/pcd2pgm) —— 基于 **ROS 2 Humble + PCL**，与本项目环境一致。

处理流程：PassThrough 高度滤波 → RadiusOutlier 去噪 → 2D 占据栅格 → 发布 `nav_msgs/OccupancyGrid` 话题 → `map_saver` 保存。

#### 安装

```bash
# 在 Ubuntu 虚拟机（ROS2 Humble）中
cd ~/ros2_ws/src
git clone https://gitee.com/LihanChen2004/pcd2pgm.git
cd ~/ros2_ws
rosdep install -r --from-paths src --ignore-src --rosdistro $ROS_DISTRO -y
colcon build --packages-select pcd2pgm
source install/setup.bash
```

#### 运行

```bash
# 终端 1：启动转换节点
ros2 launch pcd2pgm pcd2pgm.launch.py pcd_file:=/path/to/map.pcd

# 终端 2：保存栅格地图
ros2 run nav2_map_server map_saver_cli -f /path/to/output/map
```

### ④ 验证

用 RViz2 加载 `map.pgm` / `map.yaml`，或直接用 `map_server` 发布查看。

## 4. 关键参数（需实测调优）

| 参数 | 说明 | 建议初值 |
| --- | --- | --- |
| `resolution` | 栅格分辨率 | 0.05 m（Nav2 惯例） |
| PassThrough `z` 范围 | 只保留障碍物层，滤掉地面和天花板 | 0.1 ~ 1.5 m（按 MID-360 安装高度调） |
| RadiusOutlier 邻域半径 | 去孤立噪点（玻璃、反光） | 0.1 m |
| RadiusOutlier 最少邻居数 | 同上 | 5 |
| 占据阈值 | 栅格判定为障碍物的点密度阈值 | 视点云密度定 |

> 博物馆场景注意：玻璃展柜、反光展牌会产生噪点与穿透，RadiusOutlier 滤波对这类孤立噪点有效；如果墙面出现缺漏，可缩小去噪半径或提高阈值。

## 5. 备选方案

| 方案 | 说明 | 结论 |
| --- | --- | --- |
| **pcd2pgm**（推荐） | ROS2 Humble 原生，PCL，直接出 pgm | 流程最短，与环境对齐 |
| octomap_server | 经典，先建 3D OctoMap 再投影 2D | 链路重，备选 |
| grid_map_pcl（ANYbotics） | 出的是 2.5D 高程图，非 Nav2 直接吃的 pgm | 不推荐 |
| Python + Open3D 脚本 | 灵活但需自维护 | 不符合"不手敲"原则 |
