两条工作线的关系：**A 线负责铺路**——建立环境基线、验证 GLIM 建图流程可行、沉淀配置与避坑记录；**B 线负责实机**——用同一套环境接入 MID-360，完成扫描、建图与地图交付。环境一致性由同一模板镜像保证，**不需要两机交叉验证**（见 [虚拟机环境基线](01-slam/虚拟机环境基线.md) 的「环境一致性如何保证」）。

每次实验记录环境版本、仓库提交号、数据来源、配置、运行步骤、结果和已知问题。较大的原始记录与地图单独保存，在文档中记录路径，不直接提交到代码仓库。

地图数据集独立于算法和仿真程序管理。示例区域、试验区域和实际项目区域使用相同的元数据与加载接口，通过地图 ID、版本和数据集路径切换。
